# Sistema de Proyectos del Colegio (esqueleto)

Taller de Programación Avanzada - Equipo 1

## Cómo verlo
1. Clonar el repositorio.
2. Abrir la carpeta `esqueleto`.
3. Abrir `index.html` (login) en el navegador o en Nvu.

## Pantallas
- `index.html`: login
- `menu.html`: menú (proyectos, alumnos, profesores)
- `proyectos.html`: lista de proyectos con búsqueda
- `editar.html`: editar un proyecto
- `alumnos.html`: alumnos registrados
- `profesores.html`: profesores registrados
